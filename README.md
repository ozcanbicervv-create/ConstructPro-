> **A comprehensive construction project management and collaboration platform engineered for modern construction workflows, team coordination, and project excellence.**

ConstructPro transforms how construction teams plan, execute, and deliver projects by providing enterprise-grade tools specifically designed for the construction industry's unique challenges and requirements.

## 🚀 Quick Start

Get ConstructPro running locally in minutes:

```bash
# Clone the repository
git clone https://github.com/vovelet-tech/constructpro.git
cd constructpro

# Install dependencies
npm install

# Set up the database
npm run db:push
npm run db:generate

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to access ConstructPro.

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed:
- **Node.js** 18.17.0 or higher
- **npm** 9.0.0 or higher
- **Git** (latest version)

### Installation & Setup

1. **Clone and Install**
   ```bash
   git clone https://github.com/vovelet-tech/constructpro.git
   cd constructpro
   npm install
   ```

2. **Environment Configuration**
   ```bash
   cp .env.example .env.local
   # Edit .env.local with your configuration
   ```

3. **Database Setup**
   ```bash
   npm run db:generate
   npm run db:push
   npm run db:seed  # Optional: Add sample data
   ```

4. **Start Development**
   ```bash
   npm run dev
   ```

### Available Scripts

```bash
# Development
npm run dev              # Start development server with hot reload
npm run dev:debug        # Start with debugging enabled
npm run build            # Build for production
npm run start            # Start production server

# Database Operations
npm run db:generate      # Generate Prisma client
npm run db:push          # Push schema changes
npm run db:migrate       # Run database migrations
npm run db:studio        # Open Prisma Studio

# Testing & Quality
npm run test             # Run test suite
npm run test:coverage    # Run tests with coverage
npm run lint             # Run ESLint
npm run type-check       # TypeScript type checking
npm run security:audit   # Security vulnerability scan

# Performance & Analysis
npm run performance:benchmark  # Performance benchmarking
npm run bundle:analyze        # Bundle size analysis
npm run lighthouse           # Lighthouse performance audit
```
